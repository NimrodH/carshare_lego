# carshare_lego

A Babylon.js 3D world with Ready Player Me avatars: poses, walk animations and a chat between avatars.

## Run locally

GLB avatars don't load from `file://`, so serve the folder over HTTP:

```
npm install
npm run dev
```

Then open http://localhost:5500/.
